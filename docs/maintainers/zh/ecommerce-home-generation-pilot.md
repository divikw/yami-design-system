# YAMI 电商首页生成试点

参考为维护中的 `YAMI/Pages/Ecommerce Home`，使用同一份中文浅色 Storybook 夹具。
从页头看到第一个热销榜单，涵盖搜索、活动轨、快捷入口、运营条幅和商品浏览。
后续品牌、内容、推荐和页脚属于另一段页面。本轮的结论覆盖这段购物入口。
[首页 Story](../../../packages/prototypes/pages/EcommerceHome/EcommerceHome.stories.tsx)

下方保留首次生成的记录。本轮修复与独立项目验收见[组件复用试点](#组件复用试点)。

## 生成条件

独立 Vite 消费项目安装本地 `@yami/design-system@0.1.0-candidate.7`，读取安装包的
中文 Skill 和组件契约。提供从生产 Storybook 截取的两张布局参考图、浏览器测得的
区域位置和业务样例。给模型的参考图隐藏图片像素，预览通过同源活动素材和相同的前
六个热销商品呈现。任务要求保持同样的信息顺序、布局密度和主要操作。
试点摘要随仓库保留。生成会话、输入、素材路径及浏览器报告保存在执行机器的
`dist/homepage-generation/`，该目录由 Git 忽略。

## 验收条件

| 检查 | 证据 |
|---|---|
| 桌面首屏 | `1440×900` 下比较页头、四张同排活动卡、快捷入口和条幅。读实际截图，记录区块起点和宽度。 |
| 手机首屏 | `402×844` 下比较搜索、下一张活动卡露出、快捷入口和榜单出现的位置。只允许局部横向滑轨滚动。 |
| 滚动和操作 | 对照滚动后的搜索入口，实测活动翻页、分类选择、快速加购和键盘焦点。 |
| 接入 | 独立类型检查和生产构建，核对实际组件来源、图片加载、可访问性，以及宿主承担的模块。 |

若要把这段首页作为随包示例，桌面和手机应保留参考的主要构图，关键操作应可复现，
首页骨架也应能从清晰且可复用的组件契约组装。构建和类型检查只覆盖接入基础。

## 合并后独立生成

从干净的 `main` 提交 `8c28c70` 构建维护版 Storybook 和两个本地候选包。在独立 Vite
项目安装 `@yami/design-system@0.2.0-candidate.1` 和
`@yami/design-system-mcp@0.1.0-candidate.5`。Codex CLI 0.155.0 使用 `gpt-6-astra`
完成一次生成，保留首次完成的源码供验收。设计输入限于安装包、随包 Skill 和只读 MCP。
业务夹具提供维护版的中文活动素材、快捷入口、条幅和榜单前 6 件商品，并将入口映射到本地路径。
本轮覆盖中文浅色和页头至首个榜单。

会话读取了安装包内的中文 Skill，并通过 MCP 获取 `DESIGN.compact`、`DESIGN`、消费契约
及五个首页模块的组件契约和示例。33 次成功查询返回相同版本、提交和内容摘要。首次读取
规范时超出每次 200 行的上限，改用较短行段后读取成功。生成页实际使用
`StickyStorefrontHeader`、`HeroBanner`、`ShortcutRail`、`Billboard` 和 `ProductList`，
并从包中加载字体、Token 和基础样式。独立项目的类型检查和生产构建通过。

| Chromium 视口 | 维护版 | 生成版 |
|---|---|---|
| 桌面 1440 × 900 | 四张活动卡从 y147 开始，条幅的文案和行动完整进入首屏。榜单从 y935 开始。 | 活动卡仍为 324 × 365px，图片主体完整。上方留白增加，快捷入口区变高，条幅下缘超出首屏。榜单从 y1007 开始，晚 72px。 |
| 手机 402 × 844 | 首张活动卡宽 320px，下一张露出 66px。快捷入口单行，条幅显示同一活动文案，榜单从 y660 开始，首屏可见商品卡。 | 活动卡保留宽度和露出量。页头和活动区缺少随活动变化的背景，额外显示「继续购买」，快捷入口用双行，文字条幅更高。榜单从 y816 开始，首张商品卡从 y927 开始。 |

两种视口都通过滚动后搜索、活动翻页或滑动、榜单分类切换和加购反馈实测。桌面用键盘、手机用
触摸打开三类代表入口，另逐一验证 31 个独立本地目标页。搜索验证关键词交接，加购验证本地
数量从 2 到 3。对照范围内没有横向溢出或浏览器资源错误。两个版本的五个模块在首屏和滚动后

**完整首页示例暂留内部。** 现有候选包已支持用真实组件组装并完成主要操作。桌面条幅完整入屏、
手机首屏商品可见性和页面标题仍未达到随包示例的验收条件。对外消费继续使用已有的组件、契约和
单组件示例。

并排截图在 `dist/homepage-package-pilot/comparison.html`，尺寸、交互与 Axe 结果在同目录的
`browser-comparison.json`。`task.txt`、`seed/`、`model-events.jsonl`、`generated-source/` 和
