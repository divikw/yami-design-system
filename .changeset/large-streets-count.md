Add Combobox, Textarea, Field, and Tooltip as public YAMI components. Textarea retains native multiline editing and integrates with Base UI Field validation. Field connects each control to its label and feedback, with named sets and responsive groups for multi-control forms. Tooltip delegates hover, keyboard focus, and collision-aware positioning to Base UI. Include bilingual Docs and PC/Mobile stories, with tooltip placement, keyboard shortcut, and disabled action examples. The default Select trigger uses the 8px form-control radius. Input and Combobox now share 8px horizontal padding across desktop and mobile, including inline-action and chip variants.

Add DismissibleTooltip for initially open hints with a 24px close button. Both tooltip forms use 6px vertical padding, 8px horizontal padding and a 4px corner radius.
