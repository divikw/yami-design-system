Use Base UI Drawer for responsive edge panels. Mobile coupon drawers open at half height and can be dragged or expanded with the keyboard to full available height.

Drawer also supports explicit placement on all four edges, configurable snap points, a swipe handle, nested drawers and non-modal interaction. The bottom drawer centers a 100 × 6px grip 6px below the panel edge and provides a 44px-high drag target.
